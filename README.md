# Ada Ark Two Simulator

A browser walk-through and simulation of Ark Two, the community fallout shelter in Ontario, Canada, built by Bruce M. Beach. Made in his memory.

Shown in its ideal, working state.

## Layout
- `assets/` 3D model exported from Blender (glTF, metres)
- `web/` static HTML viewer (three.js), served via githack
- `ada/` simulation logic in Ada (target: WebAssembly)
- `data/` JSON: rooms, suites A-G, archive entries

## Content policy
Only our own models, code, data and cleared music live here. No third-party footage, screenshots or scans.
